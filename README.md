# Sales and Revenue Analysis Dashboard

## Project Overview
This project is an interactive Excel dashboard created to analyze sales performance, revenue, profit, and product-wise analysis using charts, pivot tables, slicers, and KPI cards.

## Features
- Total Revenue Analysis
- Profit Analysis
- Quantity Sold Tracking
- Top Performing Product
- Interactive Slicers
- Pivot Tables and Charts

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## Key Insights
- Mobile generated the highest revenue.
- Electronics category contributed maximum profit.
- Accessories products sold in higher quantity but lower profit.

## Conclusion
This dashboard helps in understanding business performance and supports better decision-making using data visualization techniques.
